# Getting Started

First, install packages:

```bash
yarn install
```

Then, run the development server:

```bash
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Technology Stack

- Rendering: React + Next.js
- Application state: Redux Toolkit
- Back-end to Front-end integration: OpenAPI Generator - [typescript-axios](https://openapi-generator.tech/docs/generators/typescript-axios/)
- Testing: Jest

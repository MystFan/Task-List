# AdList Project

adList is a multi-user solution for recording, organizing and ticking off tasks from anywhere.

It helps users to stay organized and efficient in their day-to-day office work while ensuring that
every task, no matter how small, is kept at the forefront.

With adList, all important information is available in one place: it is structured and easily
accessible. You can add due dates and mark tasks as 'Done' once they are complete.

## Prerequisites

Required:

- .NET 8.0 SDK
- NodeJS LTS

## Description

Project contains two main applications:

- API: back-end app in folder "server"
- SPA: front-end app in folder "client"

## API

ASP.NET Web API is consumed by SPA (through node.js server) and it has access to database.

## SPA

React SPA built on Next.js framework.

Go to `/src/client/README.md` to get started with the application.
